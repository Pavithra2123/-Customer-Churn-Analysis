
# Customer Churn Analysis Using Python

## Project Description
This project analyzes customer data to identify
customers who stop using a company's services.

## Objectives
- Analyze customer information
- Calculate customer churn rate
- Identify customer churn patterns
- Analyze customer contracts
- Visualize customer churn using charts

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Dataset
The project uses a sample customer dataset
containing customer ID, gender, age, tenure,
monthly charges, contract and churn status.

## Project Structure
- data/customer_data.csv
- customer_churn.py
- requirements.txt
- README.md

## How to Run

1. Install Python.
2. Install required libraries:

   pip install -r requirements.txt

3. Run the program:

   python customer_churn.py

## Output
- Customer churn rate
- Churn distribution
- Contract-wise churn analysis
- Customer churn chart
